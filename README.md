# incremental-mass-rewritten

## Mobile controls

Tap **Inspect** below the resource tiles, then tap an item to read its tooltip or
upgrade/challenge details directly in a scrollable panel, including small grid
items. Inspection does not buy upgrades or activate resets, and the original
upgrade and element layouts stay unchanged.
**Close** lets you inspect another item; **Done inspecting**
(or tapping **Inspect: ON** again) restores normal actions. Tabs remain usable
while inspecting. Desktop hover controls are unchanged.

After Infinity unlocks, the same toolbar shows your Infinity Theorem count and
progress toward the next Infinity limit, without needing to hover.
